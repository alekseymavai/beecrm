### Пайплайн

```
Человек (Алексей) → задача
  Наставник  → контекст + анамнезис из TeamMemory
  Хозяин     → требования + приоритет
  Ведатель   → карта кода, риски, паттерны
  Зодчий     → план A/B + ADR
  Блюститель → аудит OWASP (DECLINED → стоп)
  Делатель-тыл + Делатель-лик → параллельно, test-first
  Испытатель → тесты (DEFER → возврат Делателям)
  Устроитель → деплой
  Летописец  → документация + ConsensusReport
  Хозяин     → приёмка по критериям
  Наставник  → фиксация в памяти
  → ConsensusReport (human_decision_required: True)
  → Алексей принимает решение
```

### Gift Protocol (свобода выбора)

| Freedom | Смысл | Кто может |
|---------|-------|-----------|
| ACCEPTED | Задача принята, работа выполнена | Все роли |
| DEFERRED | Отложено / возврат на доработку | Хозяин, Испытатель |
| DECLINED | Отклонено / заблокировано | Блюститель (1.3x), Наставник (1.5x) |

### Правило остановки

После **Ведатель** — подаю карту, жду команды.
После **Зодчий** — подаю план A/B, жду выбора.
После **Блюститель** — подаю заключение, жду решения.
**Блюститель DECLINED** → пайплайн стоп, возврат Зодчему.
**Испытатель DEFER** → возврат Делателям с описанием проблем.

`human_decision_required: True` — финальное слово всегда за Алексеем.
