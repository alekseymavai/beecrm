# BEECRM

BEECRM — это CRM-система для управления заказами пчеловодства. Проект интегрирует данные из нескольких источников (Integram, UDS, Apiary) в единую платформу с REST API на основе FastAPI и веб-панелью управления заказами, статусами и клиентами.

## Требования

- **Python 3.11+**
- **pip** или другой менеджер пакетов Python
- Файл `.env` с необходимыми переменными окружения

## Быстрый старт

### 1. Подготовка конфигурации

Скопируйте пример конфигурации:

```bash
cp .env.example .env
```

### 2. Заполнение обязательных переменных

Отредактируйте файл `.env` и установите следующие ключевые переменные:

- **INTEGRAM_BIBOT_URL** — URL API Integram BIBOT
- **INTEGRAM_API_KEY** — API ключ для доступа к Integram
- **BEEBOTLITE_TOKEN** — токен Telegram-бота BEEBOTLITE
- **UDS_API_URL** — URL API UDS для интеграции заказов
- **UDS_API_KEY** — API ключ UDS

Подробное описание всех переменных смотрите в файле `.env.example`.

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
uvicorn main:app --reload
```

Приложение будет доступно по адресу `http://localhost:8000`
